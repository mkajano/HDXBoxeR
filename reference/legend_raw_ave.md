# Legend for average plot.

Returns legend with average plots. Preparatory function.

## Usage

``` r
legend_raw_ave(df, col, cola)
```

## Arguments

- df:

  output from functions output_tp or output_tp_proc.

- col:

  color pallette for different Protein States. As default Paired
  pallette from color.Brewer is used.

- cola:

  deprecated, use `col`.

## Value

legend for average plot for time points
