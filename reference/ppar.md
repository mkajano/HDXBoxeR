# Preparation of figure window.

Prepares a plotting window with specified margins with specific number
of figure row and columns.

## Usage

``` r
ppar(mfrow2)
```

## Arguments

- mfrow2:

  mfrow: number of Multiple Figures (use ROW-wise).

## Value

modified par function with adjusted parameters

## Examples

``` r
ppar(c(2,1))
#> NULL
```
