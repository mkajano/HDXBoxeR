# Preparatory function for volcano plot legends

Returns volcano plots

## Usage

``` r
lab_vol(df, col, cola)
```

## Arguments

- df:

  output from functions output_tp

- col:

  color pallette for different Protein States. As default Paired
  pallette from color.Brewer is used.

- cola:

  deprecated, use `col`.

## Value

legends for volcano plots
