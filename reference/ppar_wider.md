# Preparation of figure window with more area on west side of plot.

Prepares a plotting window with specified margins with specific number
of figure row and columns.

## Usage

``` r
ppar_wider(mfrow2)
```

## Arguments

- mfrow2:

  mfrow: number of Multiple Figures (use ROW-wise).

## Value

default plotting window

## Examples

``` r
ppar_wider(c(2,1))
#> NULL
```
