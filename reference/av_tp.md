# Preparatory function for average plot

Returns plots with average deuteration at each peptide.

## Usage

``` r
av_tp(df, col, cola)
```

## Arguments

- df:

  output from functions output_tp or output_tp or output_tp_proc.

- col:

  color pallette for different Protein States. As default Paired
  pallette from color.Brewer is used.

- cola:

  deprecated, use `col`.

## Value

plots of averages
